# Global E-Commerce ETL & Data Analysis Pipeline

## Project Overview

This project focuses on building an end-to-end ETL (Extract, Transform, Load) pipeline using a Global E-Commerce Sales dataset sourced from Kaggle.

The original dataset contains 2,000 records and 15 columns covering customer orders, product categories, sales, profits, and other e-commerce information.

## Dataset Information

Three versions of the dataset are maintained:

- **Original Dataset:** The unchanged dataset downloaded from Kaggle.
- **Modified Practice Dataset:** A copy of the original dataset with intentionally introduced missing values, duplicates, and inconsistent text for educational purposes.
- **Cleaned Dataset:** The processed dataset after performing data cleaning and transformation using Python and Pandas.

The deliberately introduced issues are simulated and should not be interpreted as defects identified in the original Kaggle dataset.
